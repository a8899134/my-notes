# Redis 笔记
Redis（Remote Dictionary Server）是一个开源、基于内存的键值对存储数据库，常被称为“数据结构服务器”。作为缓存和轻量级存储的首选中间件，Redis 是后端开发与运维工程师必须掌握的核心技能。
## 🧠 为什么选择 Redis
- 高性能：基于内存读写，官方基准测试可达 10 万 + QPS，响应时间在微秒级别
- 数据结构丰富：支持字符串、哈希、列表、集合、有序集合、位图、HyperLogLog、GEO、Stream 等
- 持久化保障：支持 RDB 快照 + AOF 日志双重持久化，兼顾恢复速度与数据安全
- 高可用与分布式：原生支持主从复制、哨兵自动故障转移、集群数据分片
- 生态成熟：几乎所有编程语言都有成熟的客户端，与 Spring Boot、Docker、Kubernetes 等生态无缝集成
