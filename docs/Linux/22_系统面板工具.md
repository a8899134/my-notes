Linux 系统面板工具，通俗来说就是给 Linux 服务器装上一个“图形化控制台”。你可以通过浏览器，像操作 Windows 控制面板一样，用鼠标点一点就能完成服务器管理，而不需要记住大量命令行指令。

Linux 服务器通常通过命令行(SSH)进行管理，这对初学者来说门槛较高。面板工具的作用是在服务器上运行一个 Web 服务，用户通过浏览器访问该服务，面板将复杂的命令“翻译”成可视化的按钮、图表和表单。你点一下“重启”按钮，面板在后台帮你执行 systemctl restart nginx；你填一个域名和目录，面板帮你生成完整的 Nginx 配置文件。它降低了 Linux 运维的学习门槛，也提高了日常操作的效率。

市面上常见的 Linux 面板工具很多，本文重点介绍三款具有代表性的工具：Cockpit(轻量级系统管理工具)、宝塔面板(功能全面的国产面板)和 1Panel(现代化的开源面板)。

## 一、Cockpit
### 1.1 Cockpit 简介
Cockpit 是由 Red Hat(红帽)公司开发的一款开源、轻量级的 Linux 服务器管理工具。它是一款基于 Web 的图形化界面，旨在让 Linux 系统管理员能够通过浏览器轻松管理和监控服务器。
Cockpit 的定位非常明确：它是系统管理员的“辅助驾驶舱”，而不是“自动驾驶仪”。它不会改变你原有的工作流程，你可以随时在 Cockpit 的 Web 界面和命令行终端之间自由切换。它默认使用你登录服务器时的系统账号和密码进行认证，无需额外创建用户。
适用人群： Linux 初学者、需要直观管理多台服务器的系统管理员、以及习惯命令行但希望有一个可视化概览窗口的资深运维。
### 1.2 Cockpit 的核心功能
通过 Cockpit，你可以完成以下核心任务：
- 监控系统状态：实时查看 CPU、内存、磁盘和网络的使用情况。
- 管理系统服务：启动、停止、重启和配置系统服务(如 Apache, Nginx)。
- 查看系统日志：以图形化方式浏览和搜索系统日志，快速定位错误。
- 管理存储：查看磁盘分区、格式化新磁盘、挂载文件系统。
- 配置网络：设置 IP 地址、网关、DNS 和防火墙规则。
- 用户账户管理：创建、删除用户，并管理其权限。
- 访问 Web 终端：直接在浏览器中打开一个终端窗口，执行任何命令。
### 1.3 Cockpit 的安装
Cockpit 已被纳入主流 Linux 发行版的官方软件源，安装非常便捷。RHEL/Rocky 系统上安装。
```bash
# 1. 安装 Cockpit 主程序
sudo dnf install cockpit -y

# 2. 启动 Cockpit 服务并设置开机自启
sudo systemctl enable --now cockpit.socket

# 3. 检查服务状态(确认显示 active (running))
sudo systemctl status cockpit

# 4. 防火墙放行 9090 端口(Cockpit 默认端口)
sudo firewall-cmd --add-port=9090/tcp --permanent
sudo firewall-cmd --reload
```
### 1.4 安装插件
Cockpit 的功能可以通过安装额外的插件来增强。以下是几个最常用的：
```bash
# 存储管理 (查看磁盘、LVM、RAID等)
sudo dnf install -y cockpit-storaged

# 系统日志增强查看
sudo dnf install -y cockpit-system

# 虚拟机管理 (如果使用KVM)
sudo dnf install -y cockpit-machines

# 网络管理增强
sudo dnf install -y cockpit-networkmanager
```

### 1.5 访问 Cockpit
安装完成后，在浏览器中输入 https://服务器IP:9090 即可访问。
首次访问提示： Cockpit 默认使用自签名 SSL 证书，浏览器会提示“连接不安全”，点击“高级” → “继续访问”即可。登录时使用你的系统用户名和密码(如 root 用户或具有 sudo 权限的普通用户)。
### 1.6 卸载 Cockpit
1. 停止并禁用服务：
```bash
sudo systemctl stop cockpit.socket
sudo systemctl disable cockpit.socket
sudo systemctl mask cockpit.socket  # 防止被其他依赖意外拉起
```
2. 卸载软件包 (推荐)：
```bash
sudo yum remove cockpit -y
# 同时清理相关依赖
sudo yum autoremove -y
```
3. 检查防火墙：确保 9090 端口已从防火墙规则中彻底移除。
```bash
sudo firewall-cmd --permanent --remove-service=cockpit
sudo firewall-cmd --permanent --remove-port=9090/tcp
sudo firewall-cmd --reload
sudo firewall-cmd --list-ports # 确认 9090 已消失
```
4. 检验是否卸载
```
ps -ef | grep cockpit
# 应该没有任何输出
netstat -tlnp | grep 9090    # 如果 netstat 不可用，使用 ss 替代
# 应该没有任何输出
```
### 1.7 Cockpit 的优缺点

|优点|缺点|
|---|---|
|✅ 轻量级，服务端仅占用约 20 MB 内存|❌ 功能相对基础，不具备一键建站、应用商店等高级功能|
|✅ 与系统深度集成，使用系统原生 API，不引入额外工具层|❌ 更适合系统管理，不适合需要复杂网站部署的场景|
|✅ 支持多服务器集中管理|❌ 无中文界面(但界面简单，不影响使用)|
|✅ 开源免费，无商业授权限制|—|
|✅ 内置 Web 终端，随时切换命令行操作|—|

## 二、宝塔面板
### 2.1 宝塔面板简介
宝塔面板(BT Panel)是一款国产的服务器管理软件，支持 Linux 和 Windows 系统。它凭借“一键配置 LAMP/LNMP、网站、数据库、FTP、SSL”的强大功能，在国内拥有庞大的用户群体。
宝塔面板的定位是 “一站式的服务器管理解决方案” 。它不仅提供系统监控和服务管理，更重要的是深度集成了网站部署、环境搭建和运维工具链。对于需要频繁管理网站、数据库和运行环境的用户来说，宝塔面板可以大幅提升工作效率。
适用人群： 个人站长、独立开发者、中小企业运维人员，以及希望通过图形化界面完成网站搭建和服务器管理的用户。
### 2.2 宝塔面板的核心功能
- 一键环境部署：秒级安装 LNMP (Linux+Nginx+MySQL+PHP) 或 LAMP 环境。
- 网站管理：可视化创建网站、绑定域名、配置 SSL 证书、设置伪静态。
- 数据库管理：内置 phpMyAdmin，可视化管理 MySQL/MariaDB。
- 文件管理：类似 Windows 的资源管理器，支持在线编辑、上传、解压。
- 安全防御：自带系统防火墙、SSH 端口修改、防暴力破解、网站 WAF(部分插件收费)。
- 计划任务：图形化设置定时备份、定时执行脚本。
- 软件商店：提供数十种常用软件的一键安装(如 Redis, Memcached, Node.js, Docker)。
### 2.3 宝塔面板的安装
宝塔 Linux 面板的安装非常简单，通过一条命令即可完成。
安装前须知： 建议在全新的干净系统上安装，确保系统未安装过 Apache、Nginx、PHP、MySQL 等环境，避免冲突。
1. 执行安装命令
```bash
# 使用 curl 下载安装脚本并执行
curl -sSO https://download.bt.cn/install/install_panel.sh && bash install_panel.sh
```
命令解释：
- curl -sSO：-s 静默模式(不显示进度)，-S 显示错误信息，-O 使用远程文件名保存到本地。
- bash install_panel.sh：执行下载的安装脚本。

2. 按照安装提示操作
执行命令后，安装脚本会提示是否确认安装，输入 y 后回车。脚本会自动下载并安装宝塔面板及其依赖环境。

3. 获取登录信息
安装完成后，终端会显示如下信息：
```text
外网面板地址: https://43.xxx.xxx.136:14827/d96da3eb
内网面板地址: https://192.168.x.x:14827/d96da3eb
username: xxxxxxxx
password: xxxxxxxx
```
重要提醒： 请务必保存好这些信息，特别是初始用户名和密码。
### 2.4 放行端口并访问面板
根据提示，在云服务器安全组中放行面板端口(如上例中的 14827)。然后在浏览器中访问外网面板地址，输入用户名和密码登录。
### 2.5 卸载宝塔
如果不想用了，官方提供了卸载脚本：
```bash
# 卸载前建议先执行备份
# 1. 在面板中手动备份所有网站和数据库
# 2. 或使用官方备份工具
# 3. 确认备份文件已下载到本地或云存储后再执行卸载
wget http://download.bt.cn/install/bt-uninstall.sh && sh bt-uninstall.sh
```
警告：卸载会删除所有网站数据、数据库和配置文件！操作前务必备份！
### 2.6 宝塔面板的优缺点

| 优点                       | 缺点                         |
| ------------------------ | -------------------------- |
| ✅ 功能非常全面，覆盖运维绝大部分场景      | ❌ 免费版部分高级功能受限，商业版价格较高      |
| ✅ 中文界面，对国内用户友好           | ❌ 资源占用相对较高(约 50-100 MB 内存) |
| ✅ 插件生态丰富，扩展性强            | ❌ 闭源核心，存在隐私和安全争议           |
| ✅ 社区庞大，教程和文档资源丰富         | ❌ 安装过程需要手机号注册(部分版本)        |
| ✅ 支持 Linux 和 Windows 双平台 | —                          |

## 三、1Panel
### 3.1 1Panel 简介
1Panel 是一款基于 Go 语言开发的现代化、开源的 Linux 服务器运维管理面板。项目采用 GPL v3 开源协议，由飞致云(FIT2CLOUD)团队出品。

1Panel 的定位是 “面向云原生和容器化时代的现代化面板” 。它深度拥抱 Docker 和容器技术，将网站、数据库、应用等都以容器化的方式进行管理和部署。

适用人群： 追求现代化运维体验的开发者、云原生技术爱好者、希望使用开源免费面板的用户。

### 3.2 1Panel 的核心功能
- 极致纯净：基于 Docker 部署，应用与系统环境隔离，卸载无残留，不污染宿主机。
- 安全可靠：内置 WAF 防火墙、防暴力破解、自动 SSL 证书申请，且面板自身支持隔离运行。
- 开箱即用：拥有丰富的应用商店，一键部署数十种常用软件(博客、网盘、CI/CD 工具等)。
- 现代美观：界面设计符合现代审美，操作流畅，支持深色模式，移动端适配良好。
- 高效备份：支持将数据一键备份到本地或各种云存储(S 3, OSS, COS 等)。
### 3.3 1Panel 的安装
1Panel 提供多种安装方式，推荐使用官方一键安装脚本。
```bash
# 使用官方安装脚本
curl -sSL https://resource.1panel.pro/install/install.sh | bash
```
### 3.4 卸载1Panel
```bash
# 停止 1Panel 服务
sudo systemctl stop 1panel

# 使用 1Panel 自带的命令行工具 1pctl 进行卸载。
sudo 1pctl uninstall

# 清理残余文件(可选但推荐)
sudo rm -rf /var/lib/1panel /etc/1panel /usr/local/bin/1pctl

# 验证卸载结果(可选)
sudo systemctl list-unit-files | grep 1panel
```
- 如果命令返回为空，说明 1 Panel 服务已被成功卸载。
### 3.4 1Panel 的优缺点

|优点|缺点|
|---|---|
|✅ 开源免费(GPL v 3 协议)，代码透明|❌ 功能丰富度略逊于宝塔面板(尤其在插件生态方面)|
|✅ 现代化界面设计，用户体验优秀|❌ 相对较新，社区规模和文档资源不如宝塔|
|✅ 深度拥抱 Docker 和容器化，符合云原生趋势|❌ 部分高级功能需要付费(专业版/企业版)|
|✅ 应用商店丰富，一键部署方便|—|
|✅ 不需要手机号注册即可使用|—|
|✅ 支持大语言模型(LLM)管理|—|

### 4.2 选择建议
根据你的使用场景，可以参考以下建议：

|场景|推荐工具|理由|

## 五、总结
Linux 面板工具的核心价值在于降低运维门槛、提升管理效率。三款工具各有所长：
- Cockpit 适合追求轻量、安全和系统原生体验的用户；
- 宝塔面板 适合需要全方位服务器管理、尤其是一键建站和丰富插件的用户；
- 1Panel 适合拥抱容器化、开源和现代化运维理念的用户。
无论选择哪一款，它们都只是辅助工具。理解面板背后执行的命令和系统原理，才能真正掌握 Linux 运维的核心能力。
